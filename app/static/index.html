Price Tracker

ProductsStores

A store holds the scraping rules for a site. One is created automatically the first time you add a URL from a new domain.

Store

Extraction strategies

Auto tries schema.org data, meta tags, then common price elements. CSS: .price or meta[property="og:price:amount"]|content for an attribute. Regex: first capture group, e.g. "price":\s*"(.*?)". JSON path: product.price.

Customize dashboard

Products are grouped by tag. Drag a group's title to reorder groups, drag a product to reorder it or move it to another group (which re-tags it), and use ▾ to collapse a group.

Settings

Notifications

Posts price drops, target prices reached and back-in-stock alerts to a Discord channel. In Discord: channel settings → Integrations → Webhooks → New Webhook → Copy Webhook URL.

Alerts always appear in-app. Add URLs to also send them to ntfy, Telegram, Gotify, Pushover, Slack, email and more: ntfy://ntfy.sh/topic tgram://bottoken/chatid mailtos://user:pass@gmail.com

Product search

Lets you type a product name instead of a URL, and find a product at other stores. The instance must allow the json format.

AI-assisted scraping

Used only when you turn it on for a store or click “Suggest rules with AI”. Page content is sent to the provider you choose.
